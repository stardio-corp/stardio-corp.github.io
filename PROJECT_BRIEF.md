# Stardio Official Website — Project Brief

## Purpose
Create the official Stardio homepage as a creative stationery-media brand, published with GitHub Pages.

- Repository: https://github.com/stardio-corp/stardio-corp.github.io
- Intended URL: https://stardio-corp.github.io/
- Studio People: https://studio-people-jp.github.io/
- YouTube: https://www.youtube.com/@stardio-official
- X account handle: @stardio_people (profile URL currently linked as https://x.com/stardio_people)

## Brand direction
Build a visual family with Studio People: clean white space, quiet blue accents, subtle geometric atmosphere, elegant Bodoni Moda wordmark, restrained motion, and thoughtful Japanese typography. Stardio is the umbrella/activities site, so its structure and messaging should remain distinct from the Studio People media homepage.

## Current palette
- White: #FFFFFF
- Ink Blue: #294967
- Brand Blue: #426791
- Deep Blue: #315878
- Soft Blue: #6C8AA5
- Pale Blue: #EDF3F8

## Content principles
- Activities: 人文房具, Studio People, Stardio Official.
- Describe only activities and links provided or otherwise verified.
- Do not invent registration status, company legal name, biographies, scale, or achievements.
- Avoid “Stardio株式会社” unless explicitly confirmed.

## Implementation
- Static HTML/CSS/vanilla JavaScript for a low-dependency GitHub Pages site.
- Responsive slide-out navigation, semantic sections, keyboard-visible focus, reduced-motion support.
- Main sections: Hero, Activities, About, Follow along, Footer.
- Keep external links secure with target="_blank" and rel="noopener noreferrer" where appropriate.

## Publishing checks
Confirm GitHub Pages is configured to deploy from the intended branch/folder, then check the published URL, mobile layout, external links, and browser console. A repository commit alone does not prove that Pages deployment succeeded.
